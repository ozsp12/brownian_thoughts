# Brownian Thoughts

Repository for the [Brownian Thoughts](https://www.youtube.com/@brownian-thoughts) YouTube channel. It contains supporting material for videos on physics, mathematics, data science, artificial intelligence, and related topics.

## Structure

- `videos/` — material organized by video or project
- `assets/` — reusable figures, images, and visual resources
- `references/` — papers, books, BibTeX files, and source material
- `tools/` — reusable scripts and production utilities
